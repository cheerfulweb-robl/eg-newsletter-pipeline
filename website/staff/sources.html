📖 Beginner’s Guide: How to Add a News Source
  1. Type the Name & Web Address: Enter the name of the blog, newspaper, or website, then paste its web link (URL).
  2. To grab stories just ONCE right now: Click the green One-Time Scrape Now button. You will see a list of stories — check the ones you like and click Publish Selected to Newsroom.
  3. To check this website automatically every week: Click the blue Add to Regular Scraper Schedule button. Our system will check it for new stories every Monday and Thursday morning.
  4. Manage Scheduled Sources & Blacklist: Use Run Now, Pause, Edit, or Delete on any source below, or use the Shared Blacklist at the bottom to block unwanted links or websites across the entire site.
