📖 Beginner’s Guide: How to Back Up Your Entire SiteClick to hide/show
  1. Quick Data Backup (Right Here): Click the blue Download Full Site Data Backup button below. It saves a single file containing all your events, businesses, subscribers, ads, gallery info, press releases, and blacklist rules to your computer.
  2. Full Server & Database Backup (GitHub Actions): Open your GitHub repository → Actions → Database & Data Backup → Run workflow to save a downloadable backup archive in the cloud (also runs automatically every Sunday).
  3. Store Safely: Save downloaded backup files to Google Drive, OneDrive, or an external drive so you always have an off-site copy.

3. How to Restore from a Backup

If your website or database ever needs to be rebuilt from scratch, follow these 4 steps in order:

  1. Recreate Database Tables: In a fresh Supabase project, open SQL Editor and run the files in supabase/migrations/ in date order.
  2. Restore Your Data: Either import your downloaded .json backup file (using your Supabase Service Role key or Table Editor CSV/JSON import) or restore supabase_pg_dump.sql.gz from the GitHub wg-backup-* artifact.
  3. Restore Edge Functions & Secrets: Re-enter your API secrets (ANTHROPIC_API_KEY, BREVO_API_KEY, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET) in Supabase and re-deploy the 4 functions (admin-extract-listing, admin-press-release, send-email, stripe-webhook).
  4. Re-Upload Website Files: Run python _work/build_production.py and extract the generated .zip into cPanel public_html/wg/. (Full command-line instructions are in RESTORE_RUNBOOK.md in your GitHub repo.)
