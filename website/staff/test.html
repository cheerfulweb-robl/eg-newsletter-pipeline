🚀 Launching New Build Test on GitHub Actions

Because running the full multi-site Python web crawler takes 30–60 seconds, it runs securely on your GitHub Actions server with Test Mode Safety guaranteed:

  1. Click the button below to open your private GitHub Actions pipeline:
    Open GitHub Actions Runner ↗
  2. Click "Run workflow" on the right side of the screen.
  3. Select which edition you want (reader).
  4. Check the box for "Test Run ONLY" (this ensures test_mode: true).
  5. Verify your test email (cheerfulweb@gmail.com) and click the green "Run workflow" button.
