Welcome Hamper • Participating Businesses

Redeem a Coupon Code

No business sign-in required. Enter or scan a customer’s 8-character Welcome Hamper code below to check and redeem their offer.

Tip: scanning the customer’s QR code with your phone or tablet camera opens this page with the code already filled in.

?

How Participating Businesses Use This Page

  1. Ask for the resident’s Welcome Hamper coupon: Approved new East Gwillimbury residents receive a digital Welcome Hamper wallet containing a QR code and an 8-character code starting with WG (for example, WG7K3M9Q).
  2. Scan the QR code or type the 8-character code: Point any smartphone or tablet camera at the customer’s QR code to open this page with their code pre-filled, or type the code into the box above and tap Check Code.
  3. Verify the business & offer details: The screen displays the participating business name, the exact offer title, any terms or minimum purchase notes, the resident’s first name, and whether the code is valid, expired, or already used.
  4. Tap “Redeem Now” twice to complete redemption: When the customer is ready to use the offer at checkout, tap Redeem Now and tap once more to confirm. Each code is single-use and is immediately marked as redeemed so it cannot be used again.
